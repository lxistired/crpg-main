# Banned Phrases

These phrases are outright forbidden in Script output. Any appearance = rewrite.

The list is curated from daisy-era testing where Claude kept reaching for them. Most are signature tells of **文青腔** (literary pretension), **煽情腔** (emotional overreach), or **出戏腔** (breaking immersion).

## Signature / habitual fillers

- `她的签名款` (and variants: `他一贯的`, `她惯常的`, `如往常般`, `照例`, `一如既往`)
- `打开了新的一页`
- `时间仿佛静止` / `时间如流水`
- `回忆如潮水般涌来` / `记忆突然袭来`

## Movie-reference metaphors (break the fictional world)

- `仿佛电影镜头` / `像慢镜头` / `像电影画面`
- `像极了那部老电影里的`
- `镜头推近` (narrator speaking — unless the character is *literally* operating a camera)
- `定格在那一刻`

## Overwrought time dilation

- `时间凝固` / `时间仿佛凝滞`
- `每一秒都像一个世纪`
- `一瞬间她明白了一切`
- `刹那的永恒`

## Direct emotion naming (narrator voice)

- `她感到恐惧` / `心生恐惧` / `一阵恐惧` (any bare `恐惧` with no physical grounding)
- `她愤怒地...` (as adverb narrating)
- `内心翻江倒海` / `心如刀绞` / `撕心裂肺`
- `欲哭无泪` / `欲言又止` (used 3+ times in a story)

## Lined-up adjectives

- `漆黑的、阴冷的、死寂的...`  (3+ adjectives stacked)
- `美丽、优雅、神秘...`
- Any sentence where more than 2 adjectives qualify the same noun

## Cheap escalation words (rate-limited)

These aren't outright banned but must appear **at most once per beat**:

- `突然` (not more than 1x per beat)
- `蓦地` `猛地` `忽地`
- `骤然` `陡然`

## Character-identity tropes in romance/noir

- `他就是她命中注定的那个人`
- `有些人注定只能擦肩而过`
- `爱情总是来得让人措手不及`

## "And then I understood" cliché

- `那一刻她终于明白了...`
- `多年以后她才懂得...`
- `直到那时她才意识到...`

## Sensory clichés (noir-specific)

- `夜色如墨` / `夜色漆黑`
- `华灯初上`
- `灯红酒绿` (as descriptor — fine if a character is critiquing it)

## When a banned phrase *is* allowed

Inside a character's spoken dialogue, if that character would plausibly use the phrase (for example, a character who speaks in clichés as a character trait). Banned phrases as the narrator's voice are always out.

## Detection tip

After drafting, do a grep-in-your-head for each heading above. If you feel tempted to reach for these phrases, the underlying writing is probably melodramatic — rewrite the structure of the sentence, not just the phrase.
