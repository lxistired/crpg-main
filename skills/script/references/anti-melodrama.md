# Anti-Melodrama (daisy V6, 4 rules)

Melodrama = expression exceeding the event's emotional weight. Symptoms: every scene a crisis, every character weeping, all transitions "suddenly", emotions named as bare nouns. These rules prevent the common AI-generation failure mode of writing every scene at peak intensity.

## Rule A — Don't name emotions directly. Show through action.

Emotions as bare nouns (`恐惧`, `愤怒`, `悲伤`, `心痛`, `绝望`) are narrator telling the reader what to feel. Game writing trusts the reader to read action.

- Bad: `她感到一阵恐惧。`
- Good: `她的指节在门把上发白。`

- Bad: `他愤怒地看着她。`
- Good: `他的酒杯在手里转了半圈，琥珀色液体溅到桌布上。`

**Exception**: a character can *name their own emotion in dialogue* for dramatic effect (character speaking, not narrator telling). `「我很害怕。」她说。` is allowed — rare, pointed.

## Rule B — Max ONE physical sensation per beat

Pick the strongest physical signal. Don't stack heartbeat + trembling + shortness-of-breath — that's telegraphing.

- Bad: `她心跳加速，手心出汗，呼吸变得急促，膝盖微微颤抖。`
- Good: `她听见自己的心跳——一声，两声，然后她伸手拿起电话。`

The rest of the physical state can be inferred by the reader.

## Rule C — No overwrought metaphors

Plain, precise language. Metaphors must earn their place by revealing something the literal description can't.

- Bad: `雨像利剑刺穿夜空，仿佛上天对人间的判决。`
- Good: `雨下得很密。她的鞋跟在瓷砖上敲出两记闷响。`

- Bad: `时间仿佛凝固，每一秒都是一个世纪。`
- Good: 被这句毁了的整个场景 — 删掉这句，换成一个具体动作。

Acceptable metaphor (poetic mode only): `她的红唇留在杯沿——一个淡色的弧。` (metaphor = visual image; doesn't name emotion.)

## Rule D — Not every scene is a crisis

Include humor, awkwardness, mundane texture. Constant peak intensity = no peaks. Mundane texture also makes the crises hit harder when they come.

- Bad (all 15 beats of a medium story at peak stakes): every scene has life-threatening danger or emotional catastrophe.
- Good: 2-3 peak beats spread across the arc; other beats carry tension via *potential* stakes (what might happen), awkwardness (relationship friction), or mundane texture (a shared cigarette, an umbrella purchase, waiting for a cab).

## Restraint heuristics

**If you write any of these, stop and rewrite:**

| Heuristic | Why |
|-----------|-----|
| The word `突然` more than once per beat | Cheap escalation |
| An em-dash `——` mid-sentence for dramatic pause | Overused; use a period |
| `仿佛` `宛如` `好像` to introduce metaphor more than once per beat | Novel-orientalism, not game voice |
| `一瞬间` `刹那` `片刻` | Time dilation cliché |
| Lined up adjectives (`漆黑的、阴冷的、死寂的走廊`) | Adjective vomit |
| Any sentence that starts with `那是一种...的感觉` | Direct emotion-naming under disguise |

## Mode interaction

- **Poetic mode (default)**: metaphors allowed but must earn their place (rule C). Mundane texture still required (rule D).
- **Literal mode**: metaphors strongly discouraged. Direct, concrete descriptions.
- **Extreme mode**: the 40-80 word budget enforces brevity which naturally suppresses melodrama. Still run the rules.

## Self-check before emit

Scan the output for:
- Emotion nouns as narrator voice → rewrite
- Stacked physical sensations → trim
- Metaphors that don't reveal anything new → delete
- All peak-intensity beats in a row → lower one or two
