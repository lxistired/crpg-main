# Director 对比（中文翻译）

故事情境：Su Wan 下班走出写字楼，在地铁出口花店停下看花，陌生男子递名片，她扭身离开。State = `public_formal`。6 个 shots：establishing / MS 花店 / 手 ECU 接名片 / CU 面部紧张 / 手 ECU 看名片 / 离开背影。

## Shot 01 — establishing（全身远景）

**Grok 4.20**
> anime 风格，28 岁华人女性 Su Wan，黑色中长发中分，肤白，棕眸长睫毛，柔和下颌线，红唇，红指甲，黑色包臀裙，黑丝连裤袜，黑色细跟短靴，傍晚站在现代写字楼外，柔和都市灯光，电影感 establishing shot，全身站立，优雅专业氛围。

**Sonnet 4.6**
> anime 风格，电影感插画，背景详细。Su Wan，28 岁华人女性，过肩黑色直发中分，肤白皙，棕眸长睫毛，柔软下颌线，红唇。穿一条黑色修身包臀裙过膝上沿，**黑丝自腰部连续延伸至脚**，黑色细跟踝靴。指甲涂红。她迈步走出现代写字楼的玻璃旋转门，姿态自信，皮质手袋搭在一手。下午黄金时刻光线，城市街景有行人，全身镜头，略带低角度，锐利对焦。

**差别**：Sonnet 加了"**从腰连续延伸至脚**"这种 *continuity cue*（我们 v2.1 加的那条规则）。Grok 的版本只列出"黑丝"，无延续描述——未来可能引起局部 garment 错误。

**Sonnet 4.6**
> anime 风格，电影感插画，柔暖光线。Su Wan，28 岁华人女性，过肩黑色直发中分，肤白，棕眸长睫毛，柔软下颌线，红唇，黑色修身包臀裙，手上红指甲。她微微前倾，双手轻握，目光向下带着温柔好奇，端详小花店外桶里的彩色花束。温暖橱窗光，模糊街景，腰上半身构图，中景。

## Shot 03 — 手 ECU 接名片

**Grok 4.20**
> anime 风格，纤长的手近景特写，红色长指甲，指尖微颤，正从画面外伸来的陌生人手中接过一张白色名片，柔和傍晚光线，极致细节 hand ECU，优雅紧张的姿态。

**Sonnet 4.6**
> anime 风格，ECU 极致特写，浅景深。画面中一对手：Su Wan 白皙纤长的手，每根手指涂红指甲油，向前伸出，指尖微颤，从画面右侧伸来的男性手接过一张白色名片。名片洁白有细小文字。柔和散景背景暗示花店外部，温暖环境光，hand ECU 超高细节皮肤纹理。

**差别**：Sonnet 写出"双方的手"（more storytelling）+ 名片细节（文字、洁白）+ 场景连续性（花店外部）。Grok 简洁但少叙事信息。

## 综合评估

| 维度 | Grok 4.20 | Sonnet 4.6 |
|------|-----------|------------|
| **VGAI 规则遵守** | △ **2 次出错**（shot 02 塞了腿/脚 attr，shot 06 漏红指甲） | ✓ 全部正确 |
| **continuity cue**（连续袜延伸） | 未使用 | ✓ 用了（"waist to feet"） |
| **细节层次**（gesture / 光线 / 情绪） | 简洁，缺情绪层 | 丰富（侧光投阴影 / 微颤 / 动作 micro-gesture） |
| **叙事信息密度** | 低 | 高（名片细节、手袋、台阶等） |
| **成本** | $0.008 | $0.034 |
| **速度** | 8.5s | 31.8s |

## 结论

**Director 角色 Sonnet 4.6 明显更强**——特别是 VGAI 规则遵守（Grok 出错 2 次）+ 细节层次。

所以**我们之前"Grok 做 orchestrator"的方案要修正**：

### 修正后的架构
- **Orchestrator（Director LLM）**：Sonnet 4.6（严守规则 + 丰富 prompt 细节）
  - AUP 风险：orchestrator 读的是**剧情上下文**，不是露骨文字本身
  - 如果 orchestrator 只做"分镜决策 + VGAI gating + 生成生图 prompt"，不直接生成露骨文字，Sonnet 可以做
- **露骨文字 tool**：Grok 4.20 via OpenRouter
- **克制/文艺文字 tool**：Sonnet 4.6 via OpenRouter
- **图像 tool**：Grok Imagine Pro via xAI 直连

### 但 Claude Agent SDK 还是问题
因为 SDK TOS 本身禁止 power 成人向产品。**仍然走 OpenAI Agents SDK (Apache/MIT)**，指向 OpenRouter，orchestrator 用 Sonnet 4.6。这样 SDK 干净，Sonnet 作为内容决策模型。

⚠️ **仍需验证**：Sonnet 作为 orchestrator 读到"请生成床戏分镜"这种 meta-prompt 会不会 refuse。需要专门测。
